# Jlaa Amara — Portfolio

Personal portfolio site built from Jlaa Amara’s CV: Computer Science student, full-stack projects (MedMe / Spring Boot + React), teaching assistant experience, and contact links.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy on Vercel

1. Import this GitHub repo in [Vercel](https://vercel.com/new) (account: `jlaa.amarajlaa@gmail.com`).
2. Framework preset: **Other** (static).
3. Root directory: `.` — no build command needed.
4. Deploy. Optional CLI:

```bash
npx vercel --prod
```
